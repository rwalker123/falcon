Shadow-Scale · Issue #565 · HUD palette proposal

The HUD is painted
the colour of water.

Every chrome token in HudStyle.gd — the ground, the panels, the hairlines — sits at a hue of about 193°. That is the hue of 00_deep_ocean. The land the game is actually played on sits at 19–34°. The interface and the map have been drawn from two different worlds, and the seam is what playtesters are reading as machine-made.

03 — The map's data colours

The ramps are the louder half

These live in MapView.gd, not HudStyle.gd, and they cover whole hexes rather than hairlines — so they carry more of the "AI-generated" read than the chrome does. The elevation ramp is the worst offender: blue → yellow → red is a default heatmap, not a map. Replacing it with a hypsometric tint — the convention every printed atlas uses — is the single change that most makes this look drawn by a person. These are proposed once and shared by all three directions.

Terrain textures and the blend shader are deliberately out of scope. The map art is the reference the HUD moves toward — retinting it would move the target while aiming at it.

05 — Decided

All four ship, as themes

The question this page originally asked was "which one?". The answer turned out to be "all of them", because making the palette swappable costs barely more than hardcoding one.

01
The palette becomes selectable, not baked in
const SIGNAL becomes static var SIGNAL, which reads identically at the call site — so all 710 HudStyle.* references across 58 files are untouched. All four palettes above ship; the Options pane picks between them.
02
Ember is the default
Console stays selectable, but it is no longer what a new player sees — leaving it as the default would have left the original complaint unfixed. Order in the picker: Ember, Loam, Kiln, Console.
03
Applied by rebuilding, not by restarting
A stylebox already handed to a control keeps its old colour, so nothing can be re-tinted in place. The Options row's Apply now installs the palette and then reloads the scene, in that order, so every control is built once against the new values — the same ordering the boot path already relies on. In a running game that rebuilds the world and ends the run, which the button says on its own face.
04
The ramps ship with the chrome
Console keeps its original ramps; Loam, Ember and Kiln share the earth set above, including the hypsometric elevation tint. Two hand-copied colours that bypassed HudStyle — the supply link and five overlay badges — get routed through it, or they would have stayed teal under every theme.

Still worth your eye once it's running: in Kiln, the terracotta SIGNAL and the amber HUNT_DANGER sit closer together than they do in the other three. Its DANGER has been deepened to #a8453f to open the gap, but that one is easier to judge live than from a mockup — which is now possible, because it's a theme rather than a rewrite.

All four palettes on this page ship as selectable themes, applied at launch from the Options pane. Terrain hues measured from the 38 shipped base textures; HUD hues read from HudStyle.gd and MapView.gd.
